# Instructions for the reference archive

This directory is a reusable effect archive, not an application. Read README.md, CATALOG.md and CODEX_GUIDE.md before selecting an effect. Read all four effect documents before using its code.

Preserve provenance and licenses. Distinguish original-reference observations, proposed values, implemented adaptation and actual verification. No unsupported claims of visual equivalence, device testing or 60 FPS. Never turn analysis-only into verified by assumption.

Do not migrate a target project or copy demo content automatically. Code snapshots intentionally omit media, auth, hosting and vendor; implementation.md explains dependencies. Keep one animation loop and restore lifecycle cleanup. Scope future changes to the requested effect.
