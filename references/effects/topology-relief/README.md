## Механика и границы

20 плоскостей с порогами общего поля высот образуют асимметричный ступенчатый рельеф. Scroll меняет камеру и фазу слоёв; две DOM-фразы появляются поверх сцены. Тёмная подложка закрывает сцену в контентной части, GPU приостанавливается; у footer та же render-система возвращается с другой композицией. Спектральная кромка возникает после рендера серой сцены, а не из градиента на кольцах.

PDF охватывает F01–F14: intro, рельеф, фразы, pointer/fluid, постобработку, тёмный переход, локальные reveal, Principles pin, центральное раскрытие рамок, Portfolio hover, Public goods, footer, mobile menu, якоря и scrollbar. Внешние карты, Careers, сайты компаний и юридические страницы не исследованы.

## Последовательность

Первый вход → готовый кадр/intro → hero → первая центральная фраза → вторая фраза → затемнение → обычный контент с локальными reveal → возврат рельефа у footer. Обратный scroll восстанавливает scrub-сцену; однократные reveal остаются раскрытыми. Якорный переход согласует сцену с конечной позицией без очереди wheel-твинов.

## Опорные параметры отчёта

| Параметр | Значение и статус |
| --- | --- |
| Геометрия | 20 instanced planes; height texture 256×256 — чтение кода в исходном PDF |
| Hero progress | `p=clamp(s/(4.5H),0,1)`, `τ=2+6.9p` — модель scroll-трека из отчёта |
| Footer progress | `τ=11+2q`; другая форма и FOV — чтение кода в PDF |
| Pin Principles | От 1024 px; `pinDistance=max(0,listHeight-titleHeight)` — контракт источника |
| Reveal рамки | 0.5 s центральная линия → 1.5 s раскрытие; маска от `100% 0%` к `100% 100%` |
| Меню mobile | Встречные `translateX` outer/inner; 0.8 s; закрытие обратное |

Это ориентиры отчёта, не параметры уже реализованного приложения. Формулы независимого воспроизведения, отмеченные `[ТЗ]`, отделены от `[Н]` (наблюдение) и `[К]` (сверка публичного кода).

## Условия переноса и проверка

Сохранить текущий стек, scroll-owner, маршруты, тексты и материалы целевого сайта. Three.js/GSAP/Lenis/Theatre описывают источник и возможную адаптацию; они не являются требованием установить все библиотеки. Сначала форма и глубина, затем камера/scroll, spectral pass, pointer, локальные эффекты. Не копировать bundle, логотип, портреты или фирменные тексты Topology.

В отчёте заявлены Chrome desktop 1920×897 и 1534×889, CSS viewport 390×844 и чтение JS/CSS. Физический touch, FPS, полный контраст по кадрам и fallback/reduced-motion оригинала не проверены; встречались промежуточные пустые кадры. При импорте просмотрены страницы PDF, но новый live-прогон и собственная адаптация не выполнялись.
