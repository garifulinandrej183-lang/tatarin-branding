## Сцена и геометрия

Создай один viewport-sized stage под семантическим DOM, с безопасным stacking context: scene → затемнение → контент → навигация/меню. Canvas декоративный, `aria-hidden`; не перехватывает действия UI. Локальный poster доступен до WebGL и остаётся fallback.

Для рельефа используй 20 instanced planes с общим seeded noise-height field. Независимая модель отчёта: `a_i=(i+1)/20`, `z_i=fract(a_i+cycleOffset+time*cycleSpeed)`, `threshold_i=baseHeight+depthOffset*z_i`. Маска слоя вырезает пороговый контур и учитывает соседний уровень; сглаживание связано с `fwidth`. Получи одну доминирующую впадину, плавную асимметрию и правильные перекрытия без z-fighting. `cycleSpeed=0` допустим и соответствует сохранённой настройке: постоянный autoplay не обязателен.

Сначала проверь серую форму, z-глубину и перспективу. Камера меняет pose/FOV по трекам; не заменяй её CSS scale фонового bitmap. Значения исходной камеры находятся на стр. 5 и требуют калибровки под новую геометрию; они не задают универсальные пиксельные позиции.

Добавь стилизованный свет из height-map, затем spectral composite: около пяти смещённых выборок с весами спектра после grayscale scene. FXAA, grain и нижний fade относятся к сцене; DOM остаётся резким. Grain добавь последним. Параметры `distortion≈2.016`, `bend≈-0.152` — исходные ориентиры PDF, а не гарантия совпадения.

## Scroll и состояния

Один controller/clock управляет hero, content и footer. Из layout-маркеров получай `p` и `q`; обновляй их после fonts/media ready и resize. Начальный ориентир hero — три spacer по 150dvh, `p=clamp(s/4.5H)`, `τ=2+6.9p`. Измеряй фактическую геометрию проекта и используй его scroll-контейнер.

| Фаза hero | Окно p из отчёта |
| --- | --- |
| Hero уходит | 0–0.101 |
| Первая фраза входит / удерживается / уходит | 0.077–0.242 / 0.242–0.300 / 0.300–0.459 |
| Вторая фраза входит / удерживается / уходит | 0.449–0.623 / 0.623–0.662 / 0.662–0.802 |
| Затемнение и контент | Примерно 0.89–1.00 |

Не ставь переходы в очередь по wheel. Для каждого p однозначно вычисляй позу, фразы и opacity; reverse должен воспроизводить те же состояния. Для фразы собирай enter/exit в одно итоговое свойство, чтобы два tween не перезаписывали transform.

Тёмная подложка закрывает fixed canvas. `dark=clamp((s-(E-0.5H))/(0.5H))`, где E — измеренный introEnd. При полной непрозрачности и вне footer останови render и fluid solver. Перед resume сначала выставь правильный кадр, затем снимай затемнение. Footer имеет свою форму/позу и `τ=11+2q`, а не повтор hero-кадра. Сохрани быстрые якоря, active nav и обратное движение.

## Pointer и локальные эффекты

Pointer normalised относительно viewport/container даёт малый pivot: yaw/pitch около 0.024 rad; roll зависит от разности fast/slow сглаживания. Преобразуй frame-based coefficients .032/.025 в `alpha(dt)=1-(1-alpha60)^(60dt)`, dt в секундах. Pointer не двигает DOM и не меняет scroll-progress. На coarse pointer отключи pivot и fluid-edge; не добавляй OrbitControls. При pointerleave нейтрализуй цель.

Fluid — локальное возмущение материала. Если solver заменён затухающим полем, явно укажи упрощение. Локальные эффекты подключай только в выбранных текущим запросом блоках:

- Text reveal — transform/opacity; доступный исходный текст, корректный split/revert после resize; выше якоря контент сразу видим.
- Principles pin — только от 1024 px, расстояние `max(0,listHeight-titleHeight)`; на узком экране удалить spacer/инлайновый fixed и вернуть обычный поток.
- Рамка — центральная линия scaleX 0→1 за 0.5 s, затем границы расходятся и содержимое раскрывается от центра за 1.5 s; layout-высота неизменна. Фокус немедленно раскрывает содержимое.
- Portfolio — scale внутреннего знака 1→1.03 за .4 s, слабый фон/стрелка за .3 s; ячейка не tilt. Focus-visible даёт ту же discoverability.
- Mobile menu — outer 100%→0, inner −100%→0 за .8 s; последовательные opening/open/closing, Escape, focus trap, возврат focus и снятие scroll lock.

Не морфь и не перекрашивай `made by tatarin`: официальный локальный asset, правильный вариант, подходящая нижняя область. 180 px desktop / 145 px mobile — минимумы читаемости, а не фиксированные размеры.

## Lifecycle, fallback и приёмка

Один RAF; cleanup observers/listeners/GSAP/targets/materials/geometry. Пауза при hidden и закрытой сцене. Начни с DPR≤2 desktop / ≤1.5 mobile, затем измеряй и при необходимости снижай качество. Не обещай универсальные 60 FPS. При WebGL/context/texture failure остаются poster, навигация и контент. Reduced motion: статичный рельеф, без roll/fluid/циклических стрелок, контент сразу видим; якоря работают.

Проверь p=0/.10/.25/.40/.60/.75/.95 и q=0/.5/1 в обоих направлениях; pause/resume, быстрые anchor/back-to-top, resize, шрифты и медиа. Для релевантного responsive-scope проверь 390×844, 768×1024, 1024×768, 1440×900, 1920×1080 и границы 767/768, 1023/1024, 1365/1366. Проверь клавиатуру, focus, видимость рамок, contrast на разных кадрах, ошибки загрузки и reduced motion. Физический touch и performance отдельно зафиксируй фактическими устройствами/измерениями.
