## Предлагаемая интеграция, не выполненная реализация

| Модуль | Ответственность |
| --- | --- |
| ReliefScene | Instanced planes, height field, камера, spectral/FXAA и локальное возмущение |
| ScrollDirector / MotionTimeline | Layout markers → p/q → однозначное состояние hero/content/footer |
| PointerField | Fine-pointer normalisation, dt-damping, optional fluid; не меняет DOM |
| RevealController | Только выбранные text/frame reveals и desktop pin |
| Navigation / QualityController | Действующие якоря и меню; DPR, пауза, reduced motion и poster fallback |

DOM-контракт: viewport-sized canvas под текстом, отдельная неинтерактивная dark-overlay, семантический контент в действующем scroll-owner, header/menu выше. Один animation/render clock; никакого второго Lenis поверх имеющегося. GSAP/ScrollTrigger и Three.js — возможные инструменты, Theatre для адаптации необязателен. По отчёту у источника Three.js r162 и GSAP 3.14.2; остальные версии не установлены. Эти зависимости при импорте не устанавливались.

Ресурсы целевого сайта должны быть собственными/разрешёнными и локальными. Код, модели, animated-logo, портреты и лицензии Topology не перенесены; ссылка на публичный bundle не является разрешением использовать его.
