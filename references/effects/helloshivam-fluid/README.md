## Механика

Движение → вброс скорости и цвета → перенос и смешение → затухание. Белая DOM-типографика остаётся неподвижной.

## Реализация

WebGL, vanilla JS; velocity/dye buffers. Текущая адаптация дополнена портретом и словами; это самостоятельный слой пользователя, не эффект Hello Shivam. Короткий запуск один раз на вкладку, режим статичного светящегося портрета, пауза, touch, остановка вне viewport и восстановление контекста.

## Условия переноса

Внешних JS-зависимостей нет. Нужны собственный портрет, DOM .hero-portrait/.hero-word и canvas/контролы из hero.html. Остальные site CSS и медиа не включены. Если нужен только фон, не переносить портретный слой. Сохранить LICENSE-fluid.txt (MIT Pavel Dobryakov).

Первые примеры имели отдельную 2D-симуляцию; актуальный код использует WebGL. Не выдавать ранний визуальный образец за тот же renderer. Контроллер поддерживает WebGL failure/reduced motion; окончательную ширину и яркость шлейфа проверять на целевом GPU.

Читайте документацию в указанном порядке. Числа из анализа референса и числа собственной адаптации не всегда совпадают. Ключевая часть — ввод, состояния, геометрия и движение; цвета, фото, подписи и меню менять под целевой сайт.
