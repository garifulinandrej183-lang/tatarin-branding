## Механика

Первичная разбивка изображения → дыхание границ → движение по указателю → drag-маска другой обработки → click-пересборка.

## Реализация

Canvas 2D в применении; обработанные текстуры. Восемь семейств обработок, 15 пресетов. Своя фотография, лаймовая палитра и меню; независимая адаптация идеи Quartr /nvidia. Реальная реализация использует Canvas 2D, хотя оригинальный разбор описывает WebGL.

## Условия переноса

Это buildless HTML/CSS/JS. Собственные portrait.webp, локальный шрифт Inter, иконки и официальная подпись из assets/signature репозитория. Изображения не приложены; пути в HTML — перечень ресурсов для замены. Удалить ненужный контент страницы при переносе только сцены.

Пользователь сообщал о пикселизации/мыле; здесь сохранён последний исходник, без утверждения о новом визуальном подтверждении исправления. Нужна проверка DPR, координат mask и одинакового image fit у всех обработок.

Читайте документацию в указанном порядке. Числа из анализа референса и числа собственной адаптации не всегда совпадают. Ключевая часть — ввод, состояния, геометрия и движение; цвета, фото, подписи и меню менять под целевой сайт.
