## Механика

Четыре физические плоскости → четверть оборота вокруг X → обновление граней → выбор проекта; mobile hold/shrink/turn/grow через native scroll.

## Реализация

Three.js + GSAP; применение отсутствует. Сохранён полный разбор и исходный Codex prompt. Подтверждённого собственного макета и кода переноса пока нет.

## Условия переноса

Следовать текущему стеку target. Desktop PlaneGeometry 6.4×4, mobile 3.5×6; FOV 45; GSAP turn .9 s power2.inOut. Четыре физических слота переиспользуются при числе работ >4. Полный state machine и coverScale в разборе.

WebGL референса упал в облачном браузере. Параметры подтверждались опубликованным кодом, визуальная последовательность в живом движении не проверена. Нельзя помечать этот эффект как успешно применённый или автоматически переносить pointer parallax — у оригинального hover он не обнаружен.

Читайте документацию в указанном порядке. Числа из анализа референса и числа собственной адаптации не всегда совпадают. Ключевая часть — ввод, состояния, геометрия и движение; цвета, фото, подписи и меню менять под целевой сайт.
