# tatarin-branding

Canonical brand identity and signature rules: `docs/SPECIFICATION.md` and `docs/USAGE.md`. Product UI standard: `docs/UI_GUIDELINES.md`.

Brand palette for made by tatarin: near-black `#050505`, lime `#B6F24A`, off-white `#F2F2F2`.

**Default author mark:** a native text signature `made by tatarin.` with lowercase words in off-white and only the final period in lime on dark surfaces. On light surfaces, use near-black lettering while retaining the lime dot; keep it readable. Match typography, size, and placement to the project. Do **not** require or automatically download an image. Existing official SVG/PNG signatures are optional alternatives and must stay unmodified if used.

The Tatarin palette identifies the author, not necessarily the client's product UI. Respect project-specific branding and the user's explicit requirements. Preserve existing assets unless explicitly asked to change them.

For website reference effects requested by name, URL, or mechanism, start at `references/CATALOG.md` and `references/CODEX_GUIDE.md`, then read the selected effect's analysis, prompt, and implementation notes. Follow `references/AGENTS.md` in that directory. Reuse only the requested motion pattern; do not impose a demo's content, stack, or decoration on another project.
